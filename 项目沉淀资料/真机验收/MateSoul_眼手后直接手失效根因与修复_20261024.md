# MateSoul 眼手后直接手失效根因与修复

最后更新：2026-10-24

progress_status: awaiting_post_fix_2_human

## 结论

上一轮 HUD 眼手修复在真机已验证：眼手 7 次 down / 7 次 up / 7 次 click，
食指 HUD 轻触 3 / 3 / 3，且没有指针取消或占用残留。

新问题的根因是 HUD 与世界手势仍共享 `Closed`：

1. `Closed` 使用 `graspValue >= 0.75` 进入、`graspValue <= 0.35` 才退出。
2. 眼手捏合期间 graspValue 会升高；松开后常停留在 0.6～0.7。
3. 世界抓取看到 `Closed=1` 且手边没有候选物体时，会清除 `armed`。
4. 食指触碰的 `CanPoke` 也拒绝 `Closed`。
5. 因此眼手 click 虽然完成，直接手会同时失去抓取和触碰资格，
   直到用户把手完全张开到 0.35 以下。

这不是眼手 pointer 没释放，也不是 HUD 仲裁残留。

## 修复

- `PicoTrackedHand` 改用 PICO 原生 `graspFirm` 表示真正握紧，
  不再用0.75/0.35模拟迟滞。
- 眼手 `NativePinching=1` 时抑制 `Closed`；只有检测到
  `graspFirm=0` 后才解除抑制，避免同一捏合尾部误触发世界抓取。
- `PicoDirectHandInteractor` 在任意非 firm 状态立即重新武装，
  不再要求 Grip 必须降到0.35。
- `CanPoke` 只要求食指已跟踪且未持物，不再被 Closed 误屏蔽。
- 持物时仍禁止同手点击 UI；远处 firm grasp 仍不会吸取物体；
  场景交互继续保持近距离直接手。
- 新日志使用 `runId=post-fix-2`，增加 `nativeGrasp` 和
  `graspSuppressed` 字段。
