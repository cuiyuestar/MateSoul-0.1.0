# MateSoul 物品拾取测试面板

最后更新：2026-10-27

## 使用方式

1. 在“虚拟物品”里把需要测试的物品放入房间，可分别放在地面、低台或桌面。
2. 打开“互动”，点击“物品拾取”。
3. 面板显示已放置的可移动单手物品名称及可拾取数量，每页 6 种；点击名称后，冷月走向最近的空闲实例，播放拾取与起身动画，随后保持持物。
4. 点击“放下 / 取消”解除持物并恢复物理；拾取进行中点击则取消动作。关闭面板不取消拾取，重新打开仍可放下。

没有已放置物品时，面板给出空列表提示和“去放置物品”入口。固定设施、需要双手搬运的物品不列入这组三段单手动画的测试列表。玩家持有或被其他动作占用的实例不计入可拾取数量。

## 实现

`GameHud` 增加 `PickupItems` 二级页面，沿用现有面板动画、字体和交互按钮。选择操作提交 `pickup-item` 动作及实际物品实例 ID；该动作不向 AI 公开。

`PickupItemAction` 复用 `ItemActionRun` 的预约、心跳和生命周期清理，以及 `ItemTransferStep` 的接近、站位、接触、完整起身与 Carry 过渡。步骤新增仅拾取模式，在起身后保持持物，直到取消/放下、暂停或会话结束。动作始终占有协调器的身体、移动和双臂资源，不直接从 UI 播放 Animator。

目标已经移除、被占用、固定或高度超出当前动画范围时，动作明确拒绝并显示原因。无效的新选择不会替换仍在运行的物品动作取消句柄。此入口不生成物品、不消耗库存、不触发切水果。

## 验证

本轮使用主工程的生产角色、真实 GameSession、物品预约和实际 UI 点击回放。地面、35cm 低台、78cm 桌面上放置的苹果已完成新动画拾取与起身，抓握点高度分别为 0.124m、0.474m、0.904m，持物对齐误差均小于 0.001m；暂停均清理所有权。

7 项相关回归最终通过，包括：

- 实际“物品拾取”按钮展开、空列表提示、最近空闲实例选择、真实移动、持物、关面板后继续持物及放下恢复。
- 三种支撑高度的新动画拾取、完整起身及暂停清理。
- 不存在、占用、固定和过高物品拒绝；重复请求不抢占原动作，拒绝请求不破坏取消句柄。
- 7 种物品分页、下一页/上一页按钮点击、外部占用数量即时更新、回收后列表更新和库存数量保持。
- 原有切水果取消/暂停、缺物品拒绝、对话配置及物品面板状态保持。

初轮回放脚本的进入 PlayMode 方式、HUD 状态刷新时点和跨回放按钮局部引用已调整；

不是宣称初轮全部通过。生产拾取/页面实现无需为这些测试调整增加兜底。
