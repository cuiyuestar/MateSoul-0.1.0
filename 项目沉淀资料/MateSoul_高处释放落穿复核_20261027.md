# MateSoul 高处释放落穿复核（2026-10-27）

**当前结论：INCONCLUSIVE。尚未确认用户真机故障的根因，也没有证明该故障已经修复。**

用户描述的是物品始终位于地面上方，正常拿起、高举或者轻轻向上抛后松手，随后高概率穿过地面。此前的“扫描覆盖缺口”和“强制手持目标越过地面”回放分别证明了两个独立问题，不能直接解释这一操作。本轮已更正历史报告的验证范围。

## 本轮受控证据

使用 Unity 2022.3.38f1、生产 `GameItem.Bind` / `RuntimeColliderRefiner`、实际 XRI 选择进入和退出，以及 `PicoDirectHandInteractor` 的释放路径。物品为马杯、刀、勺子、盘子、保龄球；每个物品包含普通或稳定握点抓取，并与同一释放姿态、速度下未被抓取的物品对照。

刚体原点目标高度为 0.3 / 1.0 / 1.8 m，释放速度为静止、向上 0.8 m/s、向下 0.8 m/s，另有三种初始朝向。地面包含朝上的薄 MeshCollider 和厚 BoxCollider 支撑。释放时要求整个碰撞体位于地面上方；实际记录最低下边界为 **0.13378787 m**。物理步长为生产配置的 0.02 s。
