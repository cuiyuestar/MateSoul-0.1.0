# 冷月转向与 Idle 衔接分析

日期：2026-10-23  
状态：已修复，Unity 回放验证通过；头显主观观感尚未验收。

用户猜测得到部分确认：转向未完成时，Idle 确实会反复插入。但最先触发插入的
是控制器的固定退出规则，随机 Idle 是后续放大因素。大角度、移动目标需要多次
补步本身合理，异常在于每次补步之间都交回普通 Idle。

## 事实与假设

| 假设 | 结论 | 运行证据 |
| --- | --- | --- |
| A：TurnStep 固定退出发生在朝向完成之前 | CONFIRMED | 固定 120°、48°/s，归一化时间 .975 开始退出，退出后仍剩 70.38°；原始日志 555、563 行 |
| B：随机 Idle 导致额外姿态切换 | CONFIRMED，属于放大因素 | 原始日志 566–567 行，误差约 70.38° 时 IdleVariant 从 0 变为 2；社交模式不随机换 Idle，仍出现 1.34s 间隙 |
| C：反复重置目标或反向才导致重复触发 | REJECTED，作为必要根因被排除 | 固定目标、不重置转向状态也稳定复现；反向场景确实需要改变补步方向 |
| D：脚部锁定与每步旋转预算造成剩余角度 | CONFIRMED，属于放大因素 | 不接脚部约束仍剩 66.71°，接约束剩 70.38°，所以脚部锁定并非唯一原因 |

修复前实际顺序：

1. 电机提交一次 TurnStep。
2. 控制器在片段 96% 处按 SocialAttention 分支固定回 Idle。
3. 电机发现步骤已退出，进入 0.6s recovery。
4. 剩余角度 ≥48° 时暂停根旋转，等下一次补步；小于 48° 时缓慢收尾。
5. 在 Idle 间隙里，随机待机计时可能到期并再次改变姿态。

原始日志位于本次临时采集目录，最终已清理。行号用于记录采集时的定位依据；
永久保留的数值报告为同目录
`Lengyue_转向Idle衔接_数值验证_20261023.json`。

## 修复

- `AvatarMotor` 持有一次连续转向的 `TurnStepActive` 状态。
- 一段结束后保留其尾部姿态与 0.6s recovery，左右补步直接衔接到下一段 TurnStep。
- 大误差继续补步，小误差以既有 28°/s 收尾；正常完成须剩余误差 ≤1°且转向求解器已停止。
- 电机完成或被其他动作取消后，释放 `TurnStepActive`，控制器用 0.16s 淡出回 Idle。
- 退出不再依赖 Animator exitTime，避免非循环片段尾部的归一化时间导致额外等待。
- `AvatarIdleVariation` 仅暂停真实的 TurnStep 所有权期间，保留此前修复的随机 Idle
  调度逻辑；未引入 `IsMoving`/路径存留阻塞。
- `Bind`、走路、HoldFacing 和身体接触等既有生命周期统一清理转向所有权与触发器。
- 当前正式角色、左右转身片段、GUID、动画事件和其他 Animator 业务层保持。

## 对比结果

“提前 Idle 时间”统计已进入过 TurnStep 后，剩余误差 >7° 且当前/下一状态均无
TurnStep 的时间。初始待机、完成后的待机不计入。

| 场景 | 修复前提前 Idle | 修复后提前 Idle | 正常 Play Mode 最大支撑脚位移 |
| --- | ---: | ---: | ---: |
| 固定 120°，48°/s | 1.34s | 0s | 4.81mm |
| 左转 112° | 1.42s | 0s | 5.49mm |
| 持续移动目标，4s 内每秒增加 24° | 1.80s | 0s | 5.23mm |
| 转身中途反向到 -105° | 1.28s | 0s | 6.07mm |
| 接近 180° | 1.64s | 0s | 未在该 Play Mode 组采样 |
| 社交模式 120° | 1.34s | 0s | 未在该 Play Mode 组采样 |

- 手动固定时钟回放 9 组，均最终收敛为 0°、退出 TurnStep、恢复随机待机。
- 同组验证了 movement/social 状态切换，并另行断言 HoldFacing 取消、走路打断
  在 0.24s 内释放转向动画。
- 正常 Play Mode 的 FixedUpdate / Animator / LateUpdate 时序另跑 4 组，全部通过。
  补步起点间隔约 1.66s；收敛后约 0.2s 回到 Idle。
- 当前非循环左右 Turn Clip 文件逐字节与合并提交一致。
- 修改了本地既有 `Tests/Engine/TurnInPlaceTests.cs` 的控制器契约、提前 Idle 与补步
  计数检查。该测试目录受仓库 `.gitignore` 排除；本次没有生成 NUnit XML。

## 验证边界与清理

`AvatarMotor.UpdateFacing`、Rigidbody.Simulate 与脚部 Rig。普通 Play Mode 回放用
