# MateSoul：不可移动物品放置容差与躺床方向

日期：2026-10-27。平台：Unity 2022.3.38f1 / URP / PICO Unity SDK。

## 已实现行为

1. 复古电视、饮水机、餐椅等不可移动物品放到现实扫描表面时，允许局部起伏和少量漏扫，不再要求整个支撑区域绝对平整。预览、实际放置和固定物品存档恢复共用判定。
2. 冷月躺床优先根据床面端部的枕头形状判断头向；没有明确枕头时参考床头结构，仍无法区分时使用稳定的默认方向。头尾识别失败不再阻止躺床动作。

## 放置规则

| 条件 | 本轮规则 |
| --- | --- |
| 适用范围 | 不可移动物品，支撑来自带 `RoomSurfaceCollider` 的现实扫描网格 |
| 支撑高度差 | 最大 0.08m |
| 局部支撑面法线 | y ≥ 0.5 |
| 覆盖采样 | 中心必须命中；八个周边采样至少六个有效 |
| 扫描分块 | 允许不同分块共同提供支撑 |
| 占位 | 底部 0.08m 内的扫描起伏可以容忍；上部墙体、较大凸起及其他实体仍阻止放置 |

物品自身的最小支撑面积比例继续生效。普通虚拟支撑面的原有规则保持生效；精确的高处放置失败时不会悄悄改为放到地面。

## 躺床方向

枕头提示由扫描三角形的形状推断，没有新增相机采集或视觉模型。候选必须位于床面端部，顶面最高在床面上方 0.20m 内，顶面中心至少高出 0.025m；连通顶面面积为 0.04–0.6m²，宽度为 0.18m 至 `max(0.85m, 床宽×0.9)`，纵向长度为 0.12–0.60m。一端有效面积超过另一端的 1.5 倍才采纳方向，因此两侧无法明确区分时会进入默认方向。

连续扫描在方向不明时保留已有床向。近似方形床不再要求长宽相差 0.12m；长短轴因扫描误差互换时，方向、尺寸和四边距离一起对齐已有结果。

回放还发现旧躺卧胶囊覆盖了靠枕头的颈部区域，实际阻挡上床。躺卧躯干代理高度由 1.5m 改为 1.4m，中心 y 从 0.775m 改为 0.725m，半径 0.14m、中心 z=0.145m、脚端范围保持原值；起身恢复站立胶囊。

床面完整性、人体净空、床边可达性和上床转移路径继续检查。方向兜底只解除头尾识别的阻塞；床面不存在或被实际障碍占据时仍报告原因。动作继续通过共享协调器执行，取消后恢复站姿并释放所有权。
