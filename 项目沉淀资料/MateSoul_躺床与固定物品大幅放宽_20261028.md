## 躺床规则

| 条件 | 上一轮 | 本轮 |
|---|---:|---:|
| 床面整体高度RMS上限 | 6cm | 10cm |
| 局部三角形法线竖直分量绝对值 | >0.75 | >0.6 |
| 中央7×9扫描覆盖 | ≥75% | ≥55%（至少35点） |

| 床中心位置变化容差 | 3.5cm | 6cm |

床面整体RMS不是每个点的最大起伏。接触高度仍根据躯干范围最高的允许细节调整，
实际躺卧碰撞代理保留约1cm净空。接触抬升值变化超过3.5cm仍会使锁定姿态失效。
床的尺寸和高度范围、实时Bed语义入口、枕头方向、可达床边和PhysX转移路线检查继续使用。

## 所有不可移动物品的共用规则

按`ItemDefinition.ImmovableAfterPlacement`统一应用，不使用电视或饮水机名称分支。

| 条件 | 上一轮 | 本轮 |
|---|---:|---:|
| 周边覆盖 | 扫描面至少6/8点；其他支撑面通常全覆盖 | 中心命中 + 至少3/8周边点 |
| 支撑采样范围 | 物品自身配置，常为宽长的85%–100% | 不超过物品宽长的65% |
| 扫描支撑高度差 | 8cm | 20cm |
| 非扫描支撑高度差 | 3.5cm | 8cm（固定物品） |
| 扫描支撑局部法线y | ≥0.5 | ≥0.35 |
| 非扫描支撑局部法线y | ≥0.6 | ≥0.5（固定物品） |
| 扫描面底部占位容差带 | 8cm | 20cm |
| 固定物品占位外扩 | 部分入口3cm | 统一5mm |
| 壁挂表面法线y绝对值 | ≤0.25 | ≤0.5（固定物品） |
| 壁挂支撑朝向点积 | ≥0.85 | ≥0.7（固定物品） |
| 壁挂支撑探测前后余量 | 6cm | 16cm（固定物品） |

65%是采样范围在宽、长各方向上的线性比例，不是面积覆盖百分比。
跨扫描分块支撑继续允许。上部扫描障碍和普通实体碰撞仍检查。
小于20cm的固定物品不会构造负高度的上部占位盒。

存档恢复中的固定物品使用同一套放置支撑判定；虚拟物品堆叠的支撑链必须最终
连接静态房间，不能把悬空的虚拟物品循环互认成有效支撑。普通可移动物品
保留原覆盖与物理支撑规则。无支撑的高处精确放置不会悄悄改成放到地面。
