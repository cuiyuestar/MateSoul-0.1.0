## 交互规则

1. 盐罐喷口相对世界向上方向倾斜到 160° 时开始撒盐，即距离完全倒置约 20°。
   倾角恢复到 150° 以下停止；使用迟滞避免阈值附近的闪烁。
   倒置越充分，盐的流量越高；粒子从盖孔环区域向外发射，再受重力下落。
2. 手部追踪：通过现有 XRI 选择获得瓶身，记录持握时的手指弯曲基准。
   再收紧原持握手指，增量达到 0.12 后开始挤酱，低于 0.06 停止。
   松到较放松但仍持握的状态会更新基准；捏合抓取不会被误当成挤压。
3. 手柄：沿用现有侧握抓取，读取已绑定到 UI Press 的扳机模拟量。
   扳机松开后才能触发喷酱，力度决定出料速度和软瓶形变。
4. 松手、追踪丢失、换手和恢复追踪都会停止出料并重新建立压力基准。
   暂停、应用挂起和禁用时清空效果及形变；恢复后不继承旧手的挤压力。

`SeasoningDispenser` 只拥有出料效果和 BlendShape，不改动抓取运动、
物品预约、角色 Animator 或角色动作执行。`PhysicsBody` 继续是物理运动所有者。
`PhysicsGrabInteractable.DrivingHand` 提供当前驱动手；
`PicoDirectHandInteractor.TryGetSqueezeStrength` 复用原抓取手指的有效测量。

## 性能控制

| 控制项 | 盐 | 单瓶酱 |
| --- | ---: | ---: |
| 粒子硬上限 | 768 | 160 |
| 满力度发射率 | 800 / 秒 | 180 / 秒 |
| 生命周期 | 0.38–0.65 秒 | 0.35–0.55 秒 |
| 粒子尺寸 | 0.7–1.3 mm | 4.5–6 mm |

- 每个物品只有一个根 Rigidbody 和一个 ParticleSystem；颗粒不创建独立 GameObject、
  Rigidbody、材质实例，也不发送逐粒碰撞消息。
- 粒子在世界空间模拟，瓶子移动后已撒出的粒子不随瓶子移动。
- 使用 Unity 内建中等级粒子碰撞缓存，最多 16 个碰撞形状；
  遇到世界或物品表面即结束，不积累永久盐堆或酱汁残留。
- 3 米以外停止出料，粒子离开视野时暂停模拟；软瓶离屏不继续更新蒙皮。
- 粒子不投射阴影。盐使用微小不透明颗粒；酱汁使用圆角裁切和高光的拉伸粒子，
  形成有连续感的黏稠流，不增加高面数液体网格。
- 贴图启用 Mipmap，Android 使用 ASTC 6×6，最大 512，关闭 CPU Read/Write。
- 玻璃使用支持双目实例化的 URP 轻量材质，保留透视与边缘反光。
  酱汁内层降低镜面高光，由瓶壳提供高光，以保持黑椒酱的深棕色。
