# MateSoul HUD 眼手交互与舒适距离调整

最后更新：2026-10-24

用户反馈 HUD 过高、过远，直接触碰需要伸直手臂；菜单希望恢复眼手交互，虚拟物品和角色继续保持近距离手部操作。

## 当前交互约定

| 对象 | 输入方式 |
|---|---|
| HUD 导航、对话、设置、物品目录 | 注视目标后用空手捏合，松开确认；也可食指直接触碰 |
| 场景物品拾取、角色接触 | 保留近距离手部交互 |
| 收音机、电视等物体上的按钮或旋钮 | 保留原近距离交互，不开放眼手远程操作 |
| 物品放置 | 保留手掌定位与握拳确认，HUD 的取消操作仍可用 |

HUD 可见面板中心距离从 0.65m 改为 0.45m，视野下方角度从 18° 改为 30°。保留 25% 俯仰跟随和 ±8° 限幅；低头 35° 时面板目标角度为下方 38°。点按或触碰期间完全停止位置与朝向插值。

## 实现

- `GameHud` 负责 HUD 布局与跟随，新增 HUD 专用层 `MateSoulHUD`，覆盖所有初始子节点与下拉模板。
- `HudEyeHandInteractor` 仅实现 XRI 的 `IUIInteractor`，仅注册到 UI 模块，其射线仅检测 HUD 层；无可见射线，也没有物品选择接口。
- `PicoTrackedHand` 在 UI 更新前提供同一份有效跟踪样本，增加 0.75/0.35 迟滞的捏合状态。眼睛姿态直接读取 PICO Unity SDK 的原生 gaze 特征，并检查跟踪状态与数值有效性。
- `PicoDirectHandInteractor.RefreshProximity` 让 UI 在 XRI manager 更新前也能检查当前帧掌心附近物品；物品选择与物理运动仍归原 XRI/PhysicsBody 管理。
- 正在持物、靠近可操作物品、握拳的同一只手不会触发菜单捏合；另一只空手可操作菜单。食指靠近 HUD 平面 5cm 时直接触碰优先。
- 按下后锁定发起手，跟踪失效、HUD 隐藏或触屏抢占时，以“释放且无命中”取消点击；恢复跟踪时仍捏着手指不会自动重按。
- 构建保留 HandsOnly 和 MR/房间能力，同时恢复眼睛跟踪。主场景、冷月 Prefab、Animator 控制器不重新生成。
