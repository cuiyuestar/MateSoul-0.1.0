# 抓取舒适度与冷月柔性反馈

日期：2026-10-24；平台：Unity 2022.3.38f1 / PICO Unity SDK / Android ARM64 IL2CPP。

本轮针对抓取困难、持物滑落、轻推过猛，以及冷月碰撞过早和反馈僵硬进行优化。专项隔离验收 26 项、既有回归 25 项全部通过；真人手感、动态动画叠加和头显性能待佩戴验收。

## 交互行为

- 物品仍需手部靠近后抓取。闭合门槛为 `WorldGrip >= 0.42`，支持原生捏合；两根非食指手指弯曲也可形成宽松侧握。抓取表面容差 3.2cm，关节数据不足时允许掌心距表面 6.5cm。
- 抓住后保持选择，无需持续重新证明每根手指贴合。明确张手 `WorldGrip <= 0.22` 且没有原生捏合，持续 0.16s 才释放；跟踪暂失保留最后姿态 0.28s，超过后安全释放。远处先握拳超过 0.22s 再靠近不会自动吸取。
- 每只手 17 个碰撞段改为触发传感器。只有 `ComputePenetration` 确认真实接触才请求推力，每只手对同一目标每物理帧只提交最强接触，避免多个手指重复放大力。持有物忽略同手接触，跟踪跳变不提交冲量。
- 物品接触驱动的目标速度上限 0.55m/s、加速度上限 2.5m/s²；角力矩也有上限。此限制只作用于手部推动，已有游戏力、重力和自然抛掷保持由 PhysicsBody 管理。不可移动、停靠或其他交互占用的物品不受该推力。

## 冷月接触与动作

- 对生产 Body / Face 蒙皮顶点及权重进行一次性拟合，生成 69 个细分躯干、四肢、手掌、手指、脚和头部碰撞体。接触面内收，contactOffset 为 2mm；头部随 `Head 1` 运动。头发、裙摆和宽袖不扩张身体受力范围。这是精细近似，仍需真人确认各部位的可见贴合度。
- 恢复原左右两个牵手交互点（进入 10cm / 退出 16cm）及既有 HandIKRig / HandHoldAction 的抓握、腕部限制、牵引和跟随逻辑。交互点是选择触发器，不参与身体推力。
- 轻推以阻尼关节弹簧驱动当前受力部位及邻近骨骼。肩肘腕有联动，肘膝限制为单轴，并限制继续伸直；躯干与颈头保持较小角度。此实现是受限骨骼反馈，不是完整人体生物力学仿真。
- 躯干接近速度至少 0.65m/s、压入至少 12mm、持续至少 0.14s 时，才允许一次小幅平衡步。请求位移 4–9cm、周期 0.62s、冷却 1.1s，实际位移受碰撞和运动控制器限制。双脚依次转移支撑，程序 IK 抬脚 2.5cm；不修改原动画 Clip 或 GUID。
- 反馈注册为动作协调器隐藏能力：Body / LeftArm / RightArm 分别持有控制通道，踏步持有 Locomotion。待机社交注意力允许被触碰打断；显式动作和被牵住手臂的 IK 继续保留控制权。
