# MateSoul 低头手部追踪恢复优化

> 日期：2026-10-28  
> 平台：Unity 2022.3.38f1 / URP / PICO Unity Integration SDK / XRI / Android ARM64 IL2CPP  
> 分支：`fix/hand-tracking-recovery-20261028`

本轮针对低头时手部追踪短暂失效导致抓取中断、重新拾取困难的交互问题。
软件补偿不会生成摄像头看不到的手部数据，也不能消除头显视场或遮挡限制。

## 实现

| 调整 | 生效规则 |
| --- | --- |
| 高频追踪 | `PXR_ProjectSetting.highFrequencyHand=true`，内容重建和 Android 构建入口均保留该设置。SDK 标注为 60Hz，功耗会增加；设备实际频率仍需实测。 |
| 关节位置与旋转分开验证 | 手指弯曲、接触、抓握中心及指尖方向使用当前有效位置；手掌仍要求完整有效位姿。缺少位置追踪标记、NaN 等输入仍被拒绝。 |
| 已握持物品短暂断流 | 最长 150ms 保留 XRI 选择，冻结抓取附着点；PhysicsBody 清零跟随速度，并以当前物体位姿保持跟随。 |
| 恢复连续性 | 要求恢复采样具有有效运动信息，距离最后抓握位置不超过 12cm，旋转差不超过 45°；第一恢复样本继续暂停。连续异常样本不能重置失效计时。 |
| 超时和跳变 | 安全释放，不注入旧速度；动态刚体、重力和碰撞由原物理所有者恢复。超时掉落的工具必须先张手再抓，避免握把辅助自动吸回。 |
| 正在尝试抓取 | 最长 350ms 记住失效前的握/捏意图；只接受同一目标的当前接触。超时、张手或换目标清除意图。 |
| UI 与物理推碰 | 原始追踪状态保持真实失效；失效期间不以旧关节执行 UI 指尖输入或手部物理推碰，暂停恢复期间也关闭推碰代理。 |
| 诊断 | 记录原生追踪、关节 active、状态持续时间、头部俯仰，以及 suspended/resumed/timed_out/canceled；沿用原有有界设备诊断日志。 |

XRI 继续拥有选择，PhysicsBody 继续拥有物体运动。角色牵手未沿用物品宽限，
避免旧位姿产生角色牵引；双手交接保留原有驱动者转移机制。
