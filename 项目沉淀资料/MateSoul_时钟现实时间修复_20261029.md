# 时钟现实时间同步修复

最后更新：2026-10-29

已修复正式 Clock Prefab 的固定指向偏差。时钟继续读取设备本地系统时间，忽略秒，分针每分钟跳转 6°，时针每 5 分钟跳转 2.5°。

## 根因与修复

生产 FBX 从 Blender 导入 Unity 后，指针局部 Y 轴与表盘法线一致，可以继续使用；默认角度的符号发生反转：

| 指针 | Blender 默认角度 | Unity 实际表盘角度 |
|---|---:|---:|
| 时针 | −52° | +52° |
| 分针 | +56° | −56°，等价于 304° |

旧实现把目标角度减去 Blender 默认角度，再叠加到 Unity 默认旋转，因此产生时针 +104°、分针 −112° 的固定偏差。旧测试只验证相邻时刻的旋转增量，无法发现这种偏差。

`/Users/bytedance/MateSoul/MateSoul/Assets/MateSoul/Runtime/RealTimeClock.cs` 改为将目标角度加上 Blender 默认角度，先抵消导入姿态，再显示目标时间。保留现有序列化字段及模型绑定，不需要修改 FBX、Prefab 或旧存档。

启用组件、重新显示物品、应用恢复及重新获得焦点时立即同步。常规更新仍每 0.25 秒读取一次 `DateTime.Now`，使用不受游戏暂停影响的 `Time.unscaledTime`。

## 验证

在主 Unity 工程的真实 Play Mode 中实例化正式 `Assets/MateSoul/Content/Props/Clock.prefab`，通过实际指针网格中心相对枢轴的方向计算表盘角度，不仅比较 Quaternion 增量。

| 时刻 | 修复前时针 / 分针 | 修复后时针 / 分针 |
|---|---|---|
| 00:00 | 104° / 248° | 0° / 0° |
| 03:15 | 201.5° / 338° | 97.5° / 90° |
| 06:30 | 299° / 68° | 195° / 180° |
| 09:45 | 36.5° / 158° | 292.5° / 270° |

共 12 项检查通过：

- 全天 1,440 个分钟刻度，每分钟检查第 0、30、59 秒，共 4,320 次时间采样。
- 秒不影响指针；5 分钟边界、跨午夜、跨年与时间回拨均正确。
- 平移、旋转及缩放后的钟面仍显示正确时间。
- 生成、物品重新启用、组件重新启用及恢复回调立即同步。
- `Time.timeScale = 0` 时，真实运行帧仍更新现实时间。
- 仅修改两根指针枢轴的旋转，保持网格、枢轴位置、时钟根节点和 12/3/6/9 四个数字。

最大角度误差为 **0.0003967285°**，包含任意摆放姿态的浮点误差。0° 与数值结果中的 360° 表示同一指向。

Unity 原生进程退出码为 0，耗时约 40 秒；外层工具仍报告用户级 metrics 数据库写入受限，该报告与成功的引擎验证分别记录。时钟 Prefab、FBX、角色 Prefab、Animator 控制器及主场景 SHA-256 均保持一致。临时验证入口与 meta 已从主工程移除。
